# 🏦 Bank Loan Data Analysis
## 📌 Project Overview

This project analyzes bank loan data using **SQL and Power BI** to understand loan applications, funded amounts, repayments, loan quality, and borrower behavior.

## 📊 Key KPIs

| KPI                        | Amount / Value |
| -------------------------- | -------------: |
| 💰 Total Loan Applications |     **38,576** |
| 💵 Total Funded Amount     |   **$435.76M** |
| 💳 Total Amount Received   |   **$473.07M** |
| 📈 Average Interest Rate   |     **12.05%** |
| 📊 Average DTI             |     **13.33%** |
| ✅ Good Loan Percentage     |     **86.18%** |
| ❌ Bad Loan Percentage      |     **13.82%** |

## 📈 Key Changes & Trends

* **Total funded amount:** $435.76M
* **Total amount received:** $473.07M
* **Amount received exceeded the funded amount by:** **$37.31M**
* **Good loans:** 86.18% of total applications
* **Bad loans:** 13.82% of total applications
* **Loan applications and funded amounts** were analyzed month-over-month to identify growth and declining periods.

## 🔍 Business Insights

* The majority of loans fall into the **Good Loan** category.
* The analysis highlights the difference between the **amount funded and amount received**, helping evaluate loan portfolio performance.
* Monthly trends help identify periods of increasing or decreasing lending activity.
* Borrower characteristics such as **home ownership, employment length, loan purpose and income** were analyzed to understand loan performance.
